# WisenAI

**We Turn Lifetime Expertise into Better AI**

WisenAI connects senior professionals with AI companies to create ethically-sourced, high-quality training data. We believe that decades of real-world experience make seniors uniquely qualified to help train AI systems that are accurate, helpful, and human-centered.

## What We Do

### For Seniors
- **Meaningful Work**: Share your lifetime of wisdom to help train ethical AI systems
- **Flexible Schedule**: Work from home, on your own time, with no minimum commitments
- **Fair Compensation**: Earn $15-25/hour for your valuable contributions
- **Simple Tasks**: Compare AI responses, rate quality, and share your expertise—no technical skills required

### For AI Companies
- **Premium Data**: Access ethically-sourced training data from seasoned experts
- **Domain Expertise**: Get feedback from professionals with 15+ years of real-world experience
- **Quality Assurance**: Multi-layer review process ensures high-quality outputs
- **Enterprise Security**: NDA protection and end-to-end encryption for all data

## Development

This is a [Next.js](https://nextjs.org) project deployed on Vercel.

### Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.

### Tech Stack
- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Components**: shadcn/ui
- **Icons**: Lucide React
- **Deployment**: Vercel
